# Privasi SIAGA GURU

SIAGA GURU dirancang sebagai aplikasi offline-first.

## Penyimpanan data
Data profil, siswa, absensi, jurnal, nilai, wali kelas, periode akademik, dan pengaturan disimpan di browser/perangkat pengguna menggunakan IndexedDB.

## GitHub Pages
Kode aplikasi dapat ditempatkan di GitHub Pages, tetapi data administrasi pengguna tidak otomatis dikirim ke repository GitHub.

## Backup
Pengguna bertanggung jawab melakukan backup melalui menu **Backup & Restore**. Menghapus data situs/browser, mengganti perangkat, atau mereset browser dapat menghapus data lokal.

## PIN
Fitur PIN adalah pengunci tampilan lokal dan bukan enkripsi database. Gunakan juga PIN/password perangkat dan jangan meminjamkan perangkat yang menyimpan data sekolah tanpa pengawasan.

## Data siswa
Gunakan data siswa secukupnya untuk keperluan pendidikan dan administrasi. Hindari memasukkan data sensitif yang tidak diperlukan.
