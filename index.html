Mode Lokal

SIAGA GURU tetap menyimpan data di perangkat agar bisa digunakan offline. Mode Cloud disiapkan untuk menyinkronkan ruang kerja guru antar-perangkat menggunakan Supabase.

ℹ

Gunakan Supabase Project URL dan anon/publishable key. Jangan pernah memasukkan service_role key ke aplikasi browser.
